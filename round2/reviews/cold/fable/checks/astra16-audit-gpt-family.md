## Inert newborn Monte Carlo

My `inert.cpp` simulates only cores. The core rings are a rate-`#cores` process with uniform core choice; leaf-to-parent clocks, between touches, grow each leaf count as independent Yule families (geometric increments from individual leaves, equivalently a negative-binomial sum). At a core ring the degree includes the parent or the inert slot; choosing a leaf promotes it, choosing a real core adds a leaf there, choosing the slot does nothing. Catch up the leaf Yule counts at the source and at any real destination before using them. This is exact in law apart from floating-point/PRNG implementation. `plainfar` observes one Exp(1) time divided by the requested discount on each path. Right-capping the time at `T` gives `E e^(−sσ) 1_{σ≤T}`, a lower target for each fixed depth; no total or per-depth SE includes the omitted tail bias. `strat` integrates the same exponential observation law using independent uniform times in two-unit strata weighted by `2s e^(−st)` plus a separate endpoint atom `e^(−sT)`, and estimates adjacent-ratio SEs with within-trajectory covariance (delta method). Total SE comes from the same sample's total, not from assuming depths independent.

Commands from this work directory (full outputs in the named logs). The older `inert` and current `inert_new` differ in additional endpoint diagnostics/size checks and an optional alternate allocation/control variate (`late`); the `strat`, `plainfar` and `mut` RNG/transition algorithms and estimators are unchanged.
