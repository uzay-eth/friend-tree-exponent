## Setting and statement

T_2 is the edge {1, 2}. Given T_n, choose a vertex V uniformly, then a neighbour W_n of V uniformly, and attach the new
vertex n + 1 as a leaf to W_n. F_n is the sigma-field generated by T_2, ..., T_n. D_v(n) is the degree of v in T_n
(D_v(n) = 0 if v > n); a vertex is a core vertex of T_n if its degree is at least 2; C_n is the number of core vertices;
L_v(n) is the number of neighbours of v of degree 1; c_v(n) = D_v(n) - L_v(n).

**Input.** (I) There are K < infinity and lambda < 1 with E C_n <= K n^lambda for all n >= 3. (This follows from the
round-1 theorem E C_n = n^(mu+o(1)) with mu <= 1133/2000; any lambda in (mu, 1) will do.)

**Theorem.** (a) For every v, Z_v = lim D_v(n)/n exists almost surely. (b) sum_{v >= 1} Z_v = 1 almost surely.
(c) Almost surely, sum_v |P(W_n = v | F_n) - Z_v| -> 0. (d) Almost surely, for every bounded continuous g on [0, 1],
sum_v P(W_n = v | F_n) g(D_v(n)/n) -> sum_v Z_v g(Z_v).

## Proof

**Step 1 (attachment probabilities).** For a vertex v of T_n,

    p_n(v) := P(W_n = v | F_n) = (1/n) sum_{u ~ v} 1/D_u(n),

because W_n = v exactly when V is a neighbour u of v (probability 1/n each) and u chooses v (probability 1/D_u(n)).
Each term is at most 1, so n p_n(v) <= D_v(n). Each neighbour of degree 1 contributes exactly 1 and each core
neighbour contributes 1/D_u >= 0, so

    L_v(n) <= n p_n(v) <= D_v(n),      0 <= D_v(n) - n p_n(v) <= c_v(n) <= C_n.                       (1)

(For the last inequality: the c_v(n) core neighbours of v are distinct core vertices.)

**Step 2 (supermartingale; proof of (a)).** For v <= n, D_v(n+1) = D_v(n) + 1{W_n = v}, hence

    E[D_v(n+1)/(n+1) | F_n] - D_v(n)/n = (n p_n(v) - D_v(n)) / (n (n+1)) <= 0

by (1). So (D_v(n)/n)_{n >= max(v,2)} is a supermartingale with values in [0, 1]; it converges almost surely. Call
the limit Z_v; the countably many limits exist simultaneously almost surely. This proves (a).

**Step 3 (total core degree).** T_n has n - 1 edges, so the degrees sum to 2(n - 1). The n - C_n vertices of degree 1
carry n - C_n. Hence

    sum over core vertices v of T_n of D_v(n) = n + C_n - 2.                                          (2)

**Step 4 (C_n / n -> 0 almost surely).** C_n is non-decreasing in n (a vertex of degree at least 2 keeps it). By (I)
and Markov's inequality, P(C_{2^{j+1}} > eps 2^j) <= K 2^{(j+1) lambda} / (eps 2^j), which is summable in j. By
Borel-Cantelli, almost surely C_{2^{j+1}} <= eps 2^j for all large j, and then for 2^j <= n <= 2^{j+1}:
C_n / n <= C_{2^{j+1}} / 2^j <= eps. As eps is arbitrary, C_n / n -> 0 almost surely.

**Step 5 (the degree mass of late core vertices).** Fix m >= 2 and for n >= m put

    S_n := sum of D_v(n) over the core vertices v of T_n with label v > m.

S_m = 0. At the step from T_n to T_{n+1} the new vertex n + 1 is a leaf and adds nothing to S. If W_n is a core vertex
with label > m, S increases by 1. If W_n is a leaf with label > m, it becomes a core vertex of degree 2 and S
increases by 2. Otherwise S does not change. Let q_n := P(W_n is a leaf | F_n); then E q_n = E C_{n+1} - E C_n, because
C increases (by exactly one) precisely when W_n is a leaf. Using p_n(v) <= D_v(n)/n from (1) for the core vertices,

    E[S_{n+1} - S_n | F_n] <= S_n / n + 2 q_n,     hence     E[S_{n+1}/(n+1) | F_n] <= S_n/n + 2 q_n/(n+1).

Taking expectations and summing from m to N - 1, with a_n := E C_n,

    E[S_N / N] <= 2 sum_{n=m}^{N-1} (a_{n+1} - a_n)/(n+1) =: 2 R(m, N).                              (3)

Summation by parts: sum_{n=m}^{N-1} (a_{n+1} - a_n)/(n+1) = a_N/N - a_m/(m+1) + sum_{n=m+1}^{N-1} a_n/(n(n+1)).
By (I), a_N / N <= K N^(lambda - 1) and sum_{n > m} a_n/(n(n+1)) <= K sum_{n > m} n^(lambda - 2)
<= K m^(lambda - 1)/(1 - lambda). Since N >= m,

    sup_{N >= m} E[S_N / N] <= eps(m) := 2 K m^(lambda - 1) (1 + 1/(1 - lambda)),   and eps(m) -> 0 as m -> infinity.   (4)

**Step 6 (proof of (b)).** By (2),

    (n + C_n - 2)/n = sum_{v <= m} D_v(n) 1{D_v(n) >= 2}/n + S_n/n.

On the almost sure event of Steps 2 and 4, the left side tends to 1, and each of the finitely many terms of the first
sum tends to Z_v (if D_v(n) = 1 for all n then D_v(n)/n -> 0 = Z_v; otherwise the indicator is eventually 1). Hence
S_n/n converges, and

    lim_n S_n / n = 1 - sum_{v <= m} Z_v >= 0     almost surely.                                      (5)

In particular sum_{v <= m} Z_v <= 1 for every m, so sum_v Z_v <= 1. By Fatou's lemma and (4),

    E[1 - sum_{v <= m} Z_v] = E[lim_n S_n/n] <= liminf_n E[S_n/n] <= eps(m).

The variables 1 - sum_{v <= m} Z_v decrease to 1 - sum_v Z_v >= 0 as m -> infinity, so E[1 - sum_v Z_v] <= eps(m) for all m,
hence = 0. A non-negative variable with zero mean vanishes almost surely: sum_v Z_v = 1. This proves (b).

**Step 7 (proof of (c)).** By (1), |p_n(v) - D_v(n)/n| <= C_n / n -> 0, so p_n(v) -> Z_v for every v, almost surely.
For every n, sum_v p_n(v) = 1, and sum_v Z_v = 1 by (b). For any m,

    sum_v |p_n(v) - Z_v| <= sum_{v <= m} |p_n(v) - Z_v| + (1 - sum_{v <= m} p_n(v)) + (1 - sum_{v <= m} Z_v),

and as n -> infinity the right side tends to 2 (1 - sum_{v <= m} Z_v), which tends to 0 as m -> infinity. This proves (c).

**Step 8 (proof of (d)).** For bounded continuous g and any m,

    |sum_v p_n(v) g(D_v(n)/n) - sum_v Z_v g(Z_v)|
        <= sup|g| sum_v |p_n(v) - Z_v| + sum_{v <= m} Z_v |g(D_v(n)/n) - g(Z_v)| + 2 sup|g| sum_{v > m} Z_v.

The first term tends to 0 by (c), the second by (a) and continuity of g, and the third is small for large m by (b).
The exceptional null set does not depend on g. This proves (d).

## Remarks

1. Only (I) is used, in Steps 4 and 5. The claimant's second version replaces (I) by the almost sure bound
   C_n = O(n^lambda): stop the sum S at tau = inf{n >= 3 : C_n > K n^lambda}. The indicator that the step from n to
   n + 1 is still performed, 1{tau > n}, is F_n-measurable, so the drift inequality of Step 5 can be summed over the
   performed steps, the crossing step included; C_{min(n,tau)} <= K n^lambda + 1 because C moves by at most one per step;
   on {tau = infinity} the stopped sum equals S. Then Fatou as in Step 6, m -> infinity, and finally K -> infinity.
2. Step 5 is where a cruder argument fails: the trivial bound E Z_v <= 1/v for a vertex born at time v is not
   summable. The point is that a vertex contributes to S only from its promotion on, with initial mass 2/n at
   promotion time n, and promotions at time n have probability a_{n+1} - a_n, of order n^(mu - 1).
3. (c) and (d) are the two conjectures of Section 3 of Addario-Berry, Briend, Devroye, Donderwinkel, Kerriou and Lugosi,
   "Random friend trees"; (b) is their Section 7, question 4.
