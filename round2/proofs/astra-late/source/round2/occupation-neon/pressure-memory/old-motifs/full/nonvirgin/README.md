# One full old-arm copy in the positive return

**An unlimited nonvirgin arm contributes between `.02849` and `.09543` through paths with exactly one old-child copy**, uniformly over the prior exponent interval. Allowing the first copy at any age and combining with the zero-copy class leaves the critical return from **two or more copies** in **`[.5379507439,.6612455856]`**. Neither endpoint moves. This is a statement about the original nineteen-mark trigger, independent of the D18 charges.

## Complete lineage classes

Count exactly one old-child copy, with arbitrary nontrigger direct newborn resets before and after it. The main class selects the copied arm only when the *source* is nonvirgin. A shifted copy of a virgin source belongs to the separate all-ages calculation. All intrinsic promotions and gains remain live; only the number of old-child copy traversals on the selected lineage is restricted. A direct newborn resets the marked fringe; the original particle remains live and can subsequently emit other contributions. There is no arm-size, arm-depth or lifetime cutoff.

First solve the all-degree zero-copy newborn system `v=h+A v`, with `A` the matrix of discounted nontrigger promotions from the original particle. For a general copied arm with permanent mark index `j`, let `R_j(D,k)` denote its bounded zero-further-copy value given the census. The intrinsic detached root has gain in `[L,L+k/2]`, mark death `1/j`, instantaneous trigger toll `1/2` at the virgin, and nontrigger promotion toll `v_{min(D,20)}` at `D>2`. Backward enclosures for `R_j` use the same physical branches as the newborn system, including the tail. They hold for arbitrary descendant geometries; the table does not assert the true response depends only on census.

Follow each selected arm from its actual birth on an original parent with mark index `i`. The living original parent supplies the only extra discount `λ=s+1/i`. The child's mark `a=1/j` sets its copy rates, **not an additional death while still attached**. Write `p=1/D_parent`, so `0≤p≤a`. At one emission the reward is enclosed by

```
(a−p) R_j(D,k) + p R_j(D+1,k).
```

Use the same `p` in the attached child's gain rate `g+p`; its other gains lie in `g∈[L,L+k/2]`. This yields a two-control linear-fractional comparison, retaining the exact post-promotion successor and the live gain successor for the *old* selected arm. The matched no-memory control splits `p` in the generator from `p` in the emission while preserving nonnegative emission weights summing to `a`. Other children and their complete subtrees can change the unknown rates adaptively. Linearity of expectation sums the arm values over all actual original-root births, including the virgin's half-rate promotion; no arm independence is needed. There are no pre-existing arms at each direct reset. For the attached phase only, group exterior *parent* mark indices at `{2,4,8,14,20}` by monotonicity of the original-parent discount on a nonnegative payoff. All nineteen arm marks remain separate.
