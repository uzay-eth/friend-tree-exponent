For each source group `i` and target group `j`, compute a downward-rounded discounted integral lower bound `A[i,j]` on the rate of direct promotions at capped degree in `j`. The root census runs to `D=26`; larger degrees are omitted. For the **physical** kernel there is no death, and the extra receive rate is in `[0,k/2+1/i]`. The physical class law is `β`, the birth-Palm law. For a target class `j`, the stationary physical birth fraction `β_j` is `π(b 1{capped D ∈ j})/mu`. By the stable-age identity applied with the permanent source mark attached to the tracked newborn, this is the discounted expected direct production of `j` averaged over `β` at discount `mu`. For the residual class law, use instead the normalized positive **left Perron** coefficients `ell`, combining `ell K_mu=ell` with the original-particle lower rows to obtain `ell_j≥Σ_i ell_i A[i,j]`. These are separate inequalities with separate normalized mass vectors. In particular, one may not use the stronger physical floors to weight `J G_mu`.
