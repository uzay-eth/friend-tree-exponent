# Identification of a completed oriented embedding-flow hierarchy

**Result.** Add incidence-mass projections with vanishing, explicit donor tails, and a countable collection of rational time-one cylinder tests. Every cofinal sequence of feasible relaxations then identifies the physical oriented local law; in particular every fixed labelled embedding mass and its reciprocal port converge to their physical values. This is an addition to the finite-row scheme in [`solve.py`](../solve.py), not a claim that the existing finite executable already imposes these constraints. No endpoint was recomputed.

## 1. Normalization and necessary mass cuts

Use `m(T)` for the expectation of the number of embeddings of one **labelled-role** downward tree `T`, rooted at the observed apex, in the measure `η=π/s`. The physical rate is `s=µ`. A grouped canonical column in `solve.py` has this labelled meaning, not the number of unordered copies. Write `z=η(1)`. When allowing unknown `s` in `[low,high]`, `solve.py` splits columns to make `s m(T)` lie between the endpoints: a single fixed discount model, or a vanishing mesh of discount bands, removes this relaxation. The time-one tests below use vanishing bands.

For a size-`r` pattern with censuses `(D_v,k_v)` put `K=max(1,max_v k_v)`, and let `c_x` count its specified children at role `x`. At `J≥2` sum the columns for the augmented labelled patterns over the new role's census with `D≤J`, and denote these sums by `S_child` and `S_mother`. Their defining extension maps append one labelled child at `x`, or a mother above the old apex (the old apex is her specified child). Impose

```
0 ≤ (k_x−c_x)m(T) − S_child  ≤ z K^r P_J,
0 ≤ m(T) − S_mother          ≤ z K^(r−1) P_J H_J.
```

Here `P_J,H_J` are the exact [pressure-memory products](../../pressure-memory/README.md#an-effective-joint-degree-and-child-count-tail) at `s0=565673/10^6≤µ`. These inequalities are **necessary for physical feasibility**. For the child row, reverse the incidence sum to the new high child: its mother is unique, the old apex and all intermediate ancestors on the specified path are determined, and the remaining old roles cost at most `K^r` (one can often remove factors). For the mother row, reverse to the new high mother: there are `k_mother` choices for the old apex and at most `K^(r−1)` choices for its specified descendants. In both reversals all constrained mothers outside the new role have arity at most `K`. The bounds on `π(D>J)` and `π[k;D>J]` are different and cannot be exchanged. The normalization uses `z`, not an additional factor of `1/s0` if the row already has `z`. Repeated identical siblings do not divide either side: their slots are distinct. The corresponding port rates can still use their existing sharper reciprocal remainder. A port rate alone cannot prevent mass loss at infinity since `1/D→0`.

Include these cuts for every retained pattern/slot whose one-node extension columns exist. The supplied `install_cuts(model)` imposes the nonnegative mass gap at the full cap and the upper bound at **every** `J≤cap`, together with the analogous singleton root tail `0≤z−Σ_(D≤J)m(D,k)≤zP_J` (the mass upper row is already in `solve.py`). In particular these combined rows imply uniform control of the slice `J<D≤cap`:

```
Σ_(J<D_new≤cap) m(extended tree) ≤ z K^r P_J                 (child)
Σ_(J<D_new≤cap) m(extended tree) ≤ z K^(r−1) P_J H_J         (mother).
```

The same reversal proves these bounds if used separately (then the omitted-at-cap budget is also needed). Use the corresponding bound `Σ_(J<D≤cap)m(D,k)≤zP_J` for the root. If using only the missing-at-cap cuts without additional sub-slice control, a sequence can send extension mass to censuses near the current cap; **do not** claim projectivity by taking limits of those rows alone. The sum of all fixed-census extensions equals its required mass in the completed hierarchy, by taking the limit at every fixed `J` and then letting `J→∞`.

Compactness of each fixed column does not use the growing common group bound in `solve.py`: the projection upper inequalities imply `m(T)≤z∏_v (k_v)_(c_v)` by successive labelled child insertions, even in a finite relaxation. For a port the number of spare slots bounds its mass times `1/2`. Diagonal extraction works over the countable set of individual columns. With projected extension masses tight, the two port inequalities identify each fixed reciprocal column with the sum of its exact `m(extended tree)/D_new` (the omitted rate is at most the spare-slot count times `m(T)/(cap+1)`). Physical finite restrictions give a feasible point at every level; these arguments apply to any cofinal construction retaining each required row with extension order eventually `r+1`.

## 2. Probability on a locally finite ancestor tree

Independently label each vertex's actual children by a uniform random order `1,…,k_v` (for the reverse construction this means imposing the uniformly decorated marginals). A cylinder specifies the census at each displayed vertex and for every displayed parent its children's distinct positions, which need not be consecutive. Its topology is a connected finite piece containing the distinguished vertex, its finite ancestral spine to the piece's apex, and downward children of any shown vertex. Read its probability as

```
                       m(T)
probability = -------------------------- .
                 z ∏_(v∈T) (k_v)_(c_v)
```

Retain role names and the position of the distinguished vertex, even if canonicalizing the numerator. The spine edge to the previous distinguished ancestor uses one of the `c_v` positions; it is not a separate factor or a uniformly sampled child under the mother marginal. The formula follows physically since each labelled embedding uses the prescribed ordered positions with probability `1/∏(k)_c`, and a decorated cylinder anchored at its distinguished vertex has at most one matching embedding. The same physical re-rooting counts it by summing from its apex. Symmetric roles have the same canonical mass and still distinct designated positions.

Consistency for a new child at one prescribed free position follows by summing its census over the projected row and using `(k)_(c+1)/(k)_c=k−c`. For a new mother, **sum her spine slot as well as her census**: her new factor `1/k_mother` cancels with the `k_mother` possible positions. The mother projection then gives exactly the old probability. If a spine slot is specified, leave its factor in place. These two leaf-extension operations, plus root normalization, imply consistency of arbitrary finite extensions by iteration. One concrete sequence of full reads is the marked radius-`R` ball around the distinguished vertex, with `D,k` at its boundary and positions of displayed edges. Extend the spine by one mother, then finish all the newly required child slots one by one; each local `k` is a finite integer, so finite stages give countable partitions whose probabilities sum to one by nonnegative summation. Kolmogorov's extension on the sequence of countable full-ball partitions gives a probability on consistent balls (no extraneous disconnected vertices). Take their union. Each vertex has one mother, exactly its marked finite `k` children, and `D−k−1` ordinary leaves; there are no cycles, the spine has no endpoint above the root, and the tree is locally finite. At this stage **do not** assert finite downward fringes or one end. The random orders can be forgotten for time evolution.

## 3. Generator scope and a sufficient semigroup completion

With a common discount `s`, the limiting balance equations pass for each fixed finite census pattern: included rates are finite, there are finitely many predecessor types, and reciprocal terms pass as above. Complete finite-neighbourhood indicators are finite sums of labelled occurrence tests with size/degree fixed on the read and with the appropriate slot factors (for an unordered ball sum distinct ordered assignments). Thus one gets `η A f=s η f` on these finite cylinders; all the required local gains have finite bounded target degree on the contributing reads or their one-event predecessors. These equalities are necessary, as is the semigroup identity below. They do **not** by themselves supply the reverse implication as a proof: the construction in [`operator.md` §1](../../../../../../astra/source/round2/operator.md#1-cells-and-evaluation-of-the-operator) gives uniqueness of the physical dynamics, not a generator-core or forward-equation uniqueness theorem on measures solving the indicated identities. In particular applying the balance directly to `Q_t f` needs an approximation in generator graph norm (or a controlled dual forward-equation argument), not only continuity of `Q_t f` or finite-ball approximation of its values. This note uses the following sufficient completion and makes no assertion that those extra tests are logically independent of the infinite generator rows.

For every un-oriented marked ball indicator `f`, impose finite rational outer rows targeting `η Q_1 f=e^s η f`. For a finite disjoint list `B` of ordered **input** radius-`R` cylinders let `w_B=η(B)` be the preceding linear readout without `1/z`, and let `L_B,U_B` be rigorous bounds of `Q_1 f` on that entire cylinder. Put `l≤e^s≤u` rational, `y=η(f)`. Use

```
Σ w_B ≤ z,
Σ L_B w_B ≤ u y,
l y ≤ Σ U_B w_B + 3(z−Σ w_B).
```

The coefficient 3 is valid because `Q_1 1≤e<3` by cell birth domination. These are **necessary physical** outer inequalities, not artificial exact equality to a truncated operator. If preserving a fixed band `[low,high]`, let rational `l,u` tend to `e^low,e^high` outwards. For the limit one obtains `e^low η ≤ η Q_1 ≤ e^high η` on nonnegative cylinders, which is not equality at one common eigenvalue. For identification use *vanishing bands*: enumerate subintervals of the original bracket by rational grids, run separate feasible systems, and take the union (not a single set of independently chosen discounts per row). Along extracted subsequences both band endpoints tend to a common `s`; thus `η Q_1=e^s η`. This argument can alternatively take the time-one rows alone without requiring the full generator subclass to be a core.

### Exact availability and limiting completeness of the tests

For a radius-`k` output test and an input radius `R≥k+1` ball, specify the **full ordinary leaf stock and full core degree at every displayed vertex, including every boundary vertex**. Equivalently use the full oriented census `(D,k)` with one mother; the difference between full and displayed core degree determines the retained boundary slots. Compute the old-cell truncation with the true directed rates on retained edges. By [`operator.md`, (3)](../../../../../../astra/source/round2/operator.md#1-cells-and-evaluation-of-the-operator), add outward error `min(3,9 sqrt(min(1,Σ_(w∈B_k)c_w^0/(R−k+1)!)))` and clip to `[0,3]`. This error depends only on the input ball. It tends to zero for each fixed interior, and after truncating the marked `k`-ball to finitely many reads it tends to zero uniformly. Labels of old cores track the observed root cell; each newly promoted core has its promoter's cell label. On the truncated finite old ball, stop at an **ordinary** size cap (including leaves, not retained slots). Before exit the total rate does not exceed the cap. Uniformization, with a rational enclosure of the Poisson series, computes finite rational lower/upper values. Lost paths contribute at most `sqrt(18·P(exit or Poisson truncation))` by the cell-size second moment; this remains valid if the event is not independent of cell size. The cap can grow at each fixed input since it is a finite old tree with nonexplosive size dominated by Yule. Round both square roots upwards, and **increase the rounding grid when sending the tolerance to zero** (`exact.py` accepts `grid`; the rounding excess is at most `1/grid` for each square root, before its prefactor). `exact.py` (`round2/occupation-neon/embedding-flow/identification/exact.py`, historical reference) implements the finite kernel, rational old-ball error and linear time rows; a caller supplies the finite ball readout and the output-cylinder callback. In particular the small test from a single old planted virgin, with one retained slot, has initial genuine rate `3/2`, and the no-jump indicator is enclosed by the first exact run. No real-time transcendental coefficient is needed in an LP; use a positive Taylor series with geometric remainder also for the bounds on `e^s`.

To schedule the tests without knowing the limiting measure, enumerate balls in increasing finite radius and cut budgets, and for each radius include every growing finite prefix with tighter kernel tolerance. For a specified error and fixed radius there is also an effective finite list of mass close to one by the displayed tail cuts: bound the root degree first, then extend all required slots from already capped patterns. At each extension the number of retained partial reads is finite; allocate a summable budget over steps and choose the next degree cutoff using `P_J` or `P_JH_J`. A literal level-by-level version gives a finite maximum number of slots from previous level bounds; apply the union bound to each read or path before taking the next cutoff. Use the same method to bound `B_k` first for the old-cell error. This proves explicit availability, not efficient size of the test list. In the convergence argument one may instead take finite prefixes to exhaust each countable ball partition of the reconstructed probability, then let `R→∞` and the kernel tolerance go to zero by bounded convergence. Every fixed finite linear test survives column convergence, so no probability observed only in the limit has to be approximated by a test depending on that limit.

## 4. Identification and consequence

Forget the orientation and normalize by `z`. The time-one rows and determining cylinders give a probability eigenmeasure. [`operator.md` §§3,5](../../../../../../astra/source/round2/operator.md#5-spectral-radius-from-the-uniform-one-edge-estimate) identify its eigenvalue as `e^µ` (minimality and spectral radius); [`spatial-limit.md` §2](../../../../../../astra/source/round2/fringe/spatial-limit.md#2-recovering-both-sides-of-a-rooted-ball) gives uniqueness there. Also [`spatial-limit.md` §3](../../../../../../astra/source/round2/fringe/spatial-limit.md#3-the-ordinary-finite-trees) gives exactly one end under that law. The constructed mother path is an infinite simple ray and hence necessarily points to that end, identifying the oriented law as well. This makes all subsequential limits agree, and by the finite-column bounds yields convergence of the fixed embedding and port coordinates (therefore any fixed finite linear objective). The normalization converges to `z=1/µ` by the global total constraints in the vanishing band. An objective whose support grows with the cutoff needs a separate uniform tail/absolute-integrability argument; the finite-test convergence alone is not an endpoint certificate for such an objective.
