# Astra proofs and replay

**Attribution:** Astra (GPT-6.2), source commit `2afedb1e25a6b95be30752c67022f792730d6f21`. The [Astra ledger](../../LEDGER.md#astra) gives actual review families, scopes and dependencies by claim. Christopher D. Long independently recorded the inert-newborn generation equation and its critical crossing before Astra’s marked-fringe construction. Claim 16 concerns the convergence of those physical generation sums via a different, nineteen-label operator. The Round 1 exponent and prior are inputs; see the [existence proof](source/proofs/existence.md), [almost-sure exponent](source/proofs/almost-sure-exponent.md) and [published bracket derivation](source/proofs/bracket-motifs.md).

From the release root, run `bash round2/verify/astra/run.sh`. The default suite uses Python 3.11+ (standard library only), Bash, standard Unix tools and GNU `g++` with C++20 support. Set `PYTHON` to the chosen interpreter and `TMPDIR` to an absolute scratch directory. A run with CPython 3.12.3 and GCC 13.3.0 emitted all 16 results in about 59 seconds, with peak RSS 126,328 KiB.

Original source-relative paths below are under `round2/proofs/astra/source/`. [SOURCES.tsv](SOURCES.tsv) gives the original Git object for each import. Markdown reading copies add attribution and normalize math and links without changing theorem statements. The SHA-bound originals are [physical-test.source.txt](source/round2/occupation/physical-test.source.txt) and [split-audit.source.txt](source/round2/five-next/split-audit.source.txt). The joint replay driver selects one permitted CPU and restores those bytes under the original `.md` names only in its temporary tree before manifest verification. The original manifest and checker rules are unchanged.

## Full historical replays

- `bash round2/verify/astra/run.sh spatial-full` runs the complete historical Claim 4 fixture. A recorded one-core run passed within a 90-second limit; a later short pilot timed out. Exact wall time and peak RSS were not recorded. The default runs the generator, edge-cancellation and planted-error groups.
- `bash round2/verify/astra/run.sh physical` and `physical-audits` require Linux, a GNU C/C++ toolchain (recorded GCC/G++ 13.3.0 with C++20 and UBSan), GMP development headers/libraries (recorded 6.3.0) and several GB of temporary disk space. The two regenerated witness files alone are 611,658,376 bytes each. Set `TMPDIR` to a scratch directory with room for both witnesses, comparison profiles and executables. A historical two-witness base replay with the exhaustive reserve census took 139 seconds and peaked at 1,207,936 KiB RSS; that measurement excludes the downstream affine occupation and independent audits.
- `bash round2/verify/astra/run.sh joint-preflight` isolates and checks the 74 static inputs. `joint-cold` also needs NumPy, the GNU toolchain and GMP. The original cold replay took 3,193.65 seconds; the five-pass stage alone took 2,137.56 seconds and peaked at 2,866,080 KiB under a 5 GiB virtual-memory limit. Neither run needs data from another checkout.
