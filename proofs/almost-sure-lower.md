# An almost-sure lower bound for the nucleus of the random friend tree

Model. T_2 is a single edge. Given T_n (n vertices), pick a vertex V_n uniformly, pick W_n uniformly among
the neighbours of V_n, and attach a new leaf to W_n. C_n is the number of vertices of T_n of degree >= 2
(the *core* or *nucleus*). F_n is the sigma-field generated by T_3, ..., T_n. T_3 is the path on three
vertices.

**Theorem A.** Almost surely

    liminf_{n -> infinity}  log C_n / log n  >=  0.543.

Together with the upper bound of the earlier attempt ([baseline tables](supporting-results-audit.md#the-two-baseline-tables), followed by the dyadic Markov argument:
almost surely limsup log C_n / log n <= 0.586) this gives, almost surely, for every eps > 0 and all large n,

    n^(0.543 - eps)  <=  C_n  <=  n^(0.586 + eps).

The best published almost-sure lower exponent is (sqrt(13) - 3)/6 = 0.1009 (Addario-Berry, Briend, Devroye,
Donderwinkel, Kerriou, Lugosi, *Random friend trees*, Prop. 6.20). The earlier attempt proved the exponent
0.543 only for the mean E[C_n].

Theorem A is Theorem B below applied to the final lower certificate of the earlier attempt. Theorem B is a
general transfer principle: *every* lower drift certificate of that type bounds C_n almost surely, not only
in mean.

## 1. Setting and hypotheses

Notation (as in the earlier report, §3.2-3.3). For a core vertex u of T_n: L_u = number of leaf neighbours,
c_u = number of core neighbours, D_u = L_u + c_u, and rho_u = sum of 1/D_v over the core neighbours v of u.
For n >= 3 (earlier report, Lemma 1):

* (i) for a core vertex u, P(W_n = u | T_n) = (L_u + rho_u)/n; the effect is L_u -> L_u + 1;
* (ii) for a leaf l with neighbour u, P(W_n = l | T_n) = 1/(n D_u); the effect is that l becomes a core
  vertex with (L, c) = (1, 1) and u goes from (L_u, c_u) to (L_u - 1, c_u + 1). We call this a *conversion
  at u*; its total probability is L_u/(n D_u) <= 1/n.

Nothing else happens. Note rho_u <= c_u/2, hence L_u + rho_u <= D_u.

A *local state* is a map T |-> (x_u)_{u in core(T)} assigning to every core vertex u of every tree T a state
x_u in some set X. Let f : X -> R and

    Phi_n := sum over core vertices u of T_n of f(x_u).

Hypotheses, for constants 0 < delta <= 1 and F, eta, b0, R:

* **(H1)** 0 <= f <= F, and f takes only finitely many values. Let fmin > 0 be its smallest positive value.
* **(H2)** For every n >= 3:  E[Phi_{n+1} - Phi_n | F_n] >= (delta/n) Phi_n.
* **(H3)** One step T_n -> T_{n+1} changes the value f(x_v) of at most b0 core vertices v of T_n and creates
  at most one core vertex. Hence |Phi_{n+1} - Phi_n| <= B := (b0 + 1) F.
* **(H4)** A core vertex w created at step n has f(x_w) >= eta > 0 in T_{n+1}.
* **(H5)** For every n >= 3, every T_n and every core vertex v of T_n with f(x_v) > 0:
  P( f(x_v) in T_{n+1} differs from f(x_v) in T_n | T_n ) <= R/n.

**Theorem B.** Under (H1)-(H5), almost surely liminf log C_n / log n >= delta.

## 2. Proof of Theorem B

Write Delta_n := Phi_{n+1} - Phi_n, and E_n[.] := E[. | F_n].

**Lemma 1 (conversions recur).** Almost surely C_n -> infinity; that is, conversions happen infinitely often.

*Proof.* C_n is nondecreasing, because a core vertex stays a core vertex. Fix an integer M >= 1 and let
n >= max(3, M^2 + M). On the event {C_n <= M} the n - C_n >= M^2 leaves of T_n are distributed among at most M core
vertices (for n >= 3 every leaf is adjacent to a core vertex), so some core vertex u has L_u >= M, while
c_u <= M - 1. By (ii) the conditional probability of a conversion at step n is at least
L_u/(n D_u) >= M/(n(2M - 1)) >= 1/(2n). So on the event {C_n <= M for all n} the sum over n of the
conditional probabilities of a conversion at step n, given F_n, is infinite. By the conditional
Borel-Cantelli lemma (Durrett, *Probability: Theory and Examples*, 5th ed., Thm 4.3.4), almost surely on
that event conversions happen infinitely often, which contradicts C_n <= M. Hence P(sup_n C_n <= M) = 0
for every M. ∎

**Lemma 2 (Phi is unbounded).** Almost surely sup_n Phi_n = infinity.

*Proof.* By (H1), (H2), E_n[Delta_n] >= (delta/n) Phi_n >= 0, so (Phi_n)_{n>=3} is a submartingale, and
|Delta_n| <= B by (H3). Doob decomposition: Phi_n = Phi_3 + M_n + A_n with
A_n = sum_{k=3}^{n-1} E_k[Delta_k] nondecreasing, A_n >= delta * sum_{k=3}^{n-1} Phi_k/k, and (M_n) a
martingale with increments bounded by 2B.

Let E := {sup_n Phi_n < infinity}. On E, M_n = Phi_n - Phi_3 - A_n <= sup_n Phi_n, so limsup M_n < infinity.
A martingale with bounded increments almost surely either converges to a finite limit or has
limsup = +infinity and liminf = -infinity (Durrett, Thm 4.3.1). So almost surely on E, M_n converges to a
finite limit. Then A_n = Phi_n - Phi_3 - M_n is bounded on E, so A_n converges (it is monotone), and so
does Phi_n = Phi_3 + M_n + A_n. Call the limit Phi_inf. Since sum_k Phi_k/k <= A_inf/delta < infinity and
sum_k 1/k = infinity, necessarily Phi_inf = 0.

On the other hand, by Lemma 1 conversions happen at infinitely many steps n_1 < n_2 < ..., almost surely,
and by (H4) and f >= 0, Phi_{n_i + 1} >= eta for every i. This contradicts Phi_n -> 0. Hence P(E) = 0. ∎

**Lemma 3 (the reciprocal is a supermartingale once Phi is large).** Let
kappa := 2 B delta + 4 B^2 R / fmin, fix eps in (0, delta), and let K0 := max(2B, kappa/eps). For every
n >= 3, on the event {Phi_n >= K0},

    E_n[ 1/Phi_{n+1} ]  <=  (1/Phi_n) (1 - (delta - eps)/n).

*Proof.* Write Phi = Phi_n, Delta = Delta_n, and Delta^- = max(-Delta, 0). (Convention: 1/0 = +infinity;
on the event considered, 1/Phi_{n+1} is finite for every outcome of the step.) On {Phi >= 2B} we have
Phi + Delta >= Phi - B >= Phi/2 > 0, and the algebraic identity

    1/(Phi + Delta) = 1/Phi - Delta/Phi^2 + Delta^2 / (Phi^2 (Phi + Delta))

gives 1/(Phi + Delta) <= 1/Phi - Delta/Phi^2 + 2 Delta^2/Phi^3. Since |Delta| <= B,
Delta^2 <= B |Delta| = B (Delta + 2 Delta^-). Taking conditional expectations,

    E_n[1/Phi_{n+1}] <= 1/Phi - (E_n[Delta]/Phi^2) (1 - 2B/Phi) + 4B E_n[Delta^-]/Phi^3.          (1)

The factor 1 - 2B/Phi is >= 0, so by (H2) the middle term is at most -(delta/(n Phi)) (1 - 2B/Phi). Note
that no upper bound on E_n[Delta] is needed.

Bound on E_n[Delta^-]. If Delta < 0 then, since a created vertex contributes f >= 0, some core vertex v of
T_n has a smaller value of f(x_v) in T_{n+1} than in T_n; in particular f(x_v) > 0 in T_n and f(x_v) changes.
The number of core vertices v of T_n with f(x_v) > 0 is at most Phi/fmin, and for each of them the
probability that f(x_v) changes is at most R/n by (H5). By the union bound P_n(Delta < 0) <= R Phi/(n fmin),
so E_n[Delta^-] <= B P_n(Delta < 0) <= B R Phi/(n fmin).

Inserting both bounds in (1):

    E_n[1/Phi_{n+1}] <= (1/Phi) [ 1 - (1/n) ( delta - (2 B delta + 4 B^2 R/fmin)/Phi ) ]
                      = (1/Phi) [ 1 - (1/n) ( delta - kappa/Phi ) ],

and kappa/Phi <= eps on {Phi >= K0}. ∎

**Proof of Theorem B.** Fix eps in (0, delta), K0 as in Lemma 3, and K1 > K0. Let

    sigma := inf{n >= 3 : Phi_n >= K1},      tau := inf{n >= sigma : Phi_n < K0}.

By Lemma 2, sigma < infinity almost surely. Both are stopping times. For m >= sigma let
p_m := prod_{j=sigma}^{m-1} (1 - (delta - eps)/j) in (0, 1] (each factor is positive because j >= 3 and
delta <= 1), and for n >= sigma

    G_n := 1 / ( Phi_{min(n,tau)} * p_{min(n,tau)} ).

For n >= sigma, on {n < tau} we have Phi_n >= K0, so by Lemma 3
E_n[G_{n+1}] = E_n[1/Phi_{n+1}]/p_{n+1} <= (1/Phi_n)(1 - (delta - eps)/n)/p_{n+1} = G_n; on {n >= tau},
G_{n+1} = G_n. Hence (G_{sigma+k})_{k>=0} is a nonnegative supermartingale with respect to
(F_{sigma+k})_{k>=0}, with G_sigma = 1/Phi_sigma <= 1/K1. (Details for the random starting time: G_{sigma+k}
is F_{sigma+k}-measurable and bounded by (K0 - B)^(-1) (1 - (delta - eps)/3)^(-k), because Phi_{min(n,tau)}
>= K0 - B > 0; for A in F_{sigma+k} one splits A into the pieces A intersected with {sigma + k = n}, which
lie in F_n, applies the inequality above on each piece, and sums.) Two consequences:

* *(a)* By the maximal inequality for nonnegative supermartingales, P(sup_k G_{sigma+k} >= 1/K0) <= K0/K1.
  On {tau < infinity}, G_tau = 1/(Phi_tau p_tau) > 1/K0 because Phi_tau < K0 and p_tau <= 1. Hence
  P(tau < infinity) <= K0/K1.
* *(b)* G_n converges almost surely to a finite limit, so G* := sup_{n >= sigma} G_n < infinity almost
  surely. On {tau = infinity}, for all n >= sigma, Phi_n = 1/(G_n p_n) >= 1/(G* p_n), and
  p_n <= exp(-(delta - eps) sum_{j=sigma}^{n-1} 1/j) <= (sigma/n)^(delta - eps). So
  Phi_n >= (n/sigma)^(delta - eps)/G* for all n >= sigma, and therefore
  liminf log Phi_n / log n >= delta - eps on {tau = infinity}.

So P(liminf log Phi_n/log n >= delta - eps) >= 1 - K0/K1 for every K1 > K0, hence it equals 1. Since
C_n >= Phi_n/F by (H1), almost surely liminf log C_n/log n >= delta - eps. Let eps -> 0 along a sequence. ∎

## 3. Proof of Theorem A: the hypotheses hold for the certificate of the earlier attempt

The [lower baseline certificate](../verify/baseline/certs9.py) uses $`L_{\max}=60`$, $`c_{\max}=10`$, $`K_0=2`$, $`D_{\rm cap}=6`$ and $`\delta=543/1000`$.

*State.* From the point of view of a core vertex v, each core neighbour w has a **class**, a function of
(L_w, c_w) alone:

* P_l (pendant of class l), l in {1, 2}, if (L_w, c_w) = (l, 1);
* B if (L_w, c_w) = (0, 2);
* O_d, d in {3, 4, 5}, if w is neither pendant nor B and D_w = d;
* top, if w is neither pendant nor B and D_w >= 6.

A vertex with D_w >= 6 = Dcap has class top (pendants have D <= 3, class B has D = 2). The state is
x_v = (L_v, c_v, m_1, m_2, b, n_3, n_4, n_5): its own (L, c) and the numbers of core neighbours of each
class (the number of top neighbours is the rest). f is a finite table on L <= 60, c <= 10, extended by
f(L, .) = f(60, .) for L > 60 and f = 0 for c > 10.

*(H1).* f >= 0 and the table is finite; checked in exact arithmetic by `as_lower_check.py` (sup f, fmin
printed in the log).

*(H2).* The baseline reduction classifies changes of the focal vertex and of every core neighbour and charges the newborn once to its creator. Its endpoint checks cover both unbounded coordinates. The lower verifier bounds every such row below by $`\delta f`$, so summing over core vertices gives $`n\,\mathbb E_n[\Delta_n]\ge\delta\Phi_n`$ on every tree of size at least three. [Full reduction and tail endpoints](supporting-results-audit.md#the-two-baseline-tables) · [Exact lower verifier](../verify/baseline/certs9.py)

*(H3) with b0 = Dcap = 6.* A step is of type (i) or (ii).
(i) W_n = w is a core vertex: only (L_w, c_w) changes among all pairs (L, c), by L_w -> L_w + 1. So x_w
changes, and x_v changes for another core vertex v only if v is a core neighbour of w and the class of w
changes. A top vertex stays top (degrees do not decrease and a vertex of degree >= 6 is never pendant or
B), so the class of w changes only if D_w <= 5 before the step, and then w has at most 5 core neighbours.
At most 1 + 5 = 6 states change; no core vertex is created.
(ii) W_n = l is a leaf of u: (L_u, c_u) -> (L_u - 1, c_u + 1), and l becomes a core vertex w with
(L_w, c_w) = (1, 1); no other pair (L, c) changes. So x_u changes, w is created, and for a core neighbour
v != w of u the state x_v changes only if the class of u changes. If c_u = 0 before the step (possible only
for the centre of a star) there is no such v. If c_u >= 2 before the step, u was O_d or
top (not B, because L_u >= 1), D_u does not change, and afterwards c_u >= 3, so u is still neither pendant
nor B: same class. If c_u = 1 before the step, u was pendant or O_d or top and v is its only core neighbour.
So at most 2 existing states change and one vertex is created.
Hence |Delta_n| <= (6 + 1) F.

*(H4).* The newborn w of a conversion at u is in state (1, 1, .) with one core neighbour u, whose class is
determined by (L_u, c_u). `as_lower_check.py` lists all possible newborn states (7 of them) and checks in
exact arithmetic that f > 0 on each; eta is the smallest of these values.

*(H5) with R = Lmax + cmax/2 + 1 + cmax * Dcap = 126.* Let v be a core vertex with f(x_v) > 0; then
c_v <= cmax = 10. By the case analysis in (H3), f(x_v) can change in one step only if one of the following
happens.
(a) W_n = v and L_v < Lmax (for L_v >= Lmax the new state has the same f-value by the extension rule).
Probability (L_v + rho_v)/n <= (Lmax + cmax/2)/n.
(b) A conversion at v. Probability <= 1/n.
(c) W_n = w for a core neighbour w of v with D_w <= Dcap - 1 (otherwise the class of w does not change).
Probability (L_w + rho_w)/n <= D_w/n <= (Dcap - 1)/n for each of the at most cmax neighbours.
(d) A conversion at a core neighbour w of v. Probability <= 1/n for each of the at most cmax neighbours.
The sum is at most (Lmax + cmax/2 + 1 + cmax * Dcap)/n. ∎

From the repository root, `bash verify/run_all.sh` runs the exact baseline and (H1)–(H5) checks in the `almost-sure-lower` suite. [Verification guide](../verify/README.md)

## 4. Remarks

1. Theorem B applies to any future lower certificate with a vertex-additive potential, provided all five
   hypotheses are re-checked for it: (H1) f >= 0 with finitely many values, (H2) the drift inequality,
   (H3) a bounded number of f-values changed per step, (H4) a positive lower bound on the value of every
   newborn, and (H5) bounded local rates on the support of f. (H3) and (H4) are used in the proof (bounded
   increments; Phi does not die out) and do not follow from (H2). Under these hypotheses a certified lower
   exponent for the mean is automatically an almost-sure lower exponent.
2. The proof does not use an upper bound on C_n. The only place where "f = 0 on dead states" could hurt
   is the control of the fluctuations of Phi; upward jumps are absorbed by the drift term in (1), and
   downward jumps can only come from vertices that carry positive value, whose number is at most Phi/fmin.
3. No statement is made about the existence of lim log C_n/log n.
